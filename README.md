# Full Gov

`full-gov` is a repo that contains 3 different projects:

- my-city-gov
- noc-gov
- noc-sms

## My City Gov

`my-city-gov` is the main project that runs the application.

## Noc Gov

`noc-gov` is a database that holds the data of the citizens.

## Noc Sms

`noc-sms` is a Mock SMS service that authenticates the citizens.


## How to run

All 3 projects have instructions on how to run them inside them.

For the main application to run successfully (`my-city-gov`), the other 2 projects must be running.
